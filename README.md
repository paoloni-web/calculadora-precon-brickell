# Calculadora Precon Brickell

Calculadora de inversión de One Twenty Brickell · Signature. Página estática publicada con GitHub Pages:
cada cambio que se sube a la rama `main` queda en línea en uno o dos minutos.

## Cómo hacer cambios

- **Unidades (precios, rentas, gastos, añadir o quitar):** editar `unidades.js`. Las instrucciones están al principio del archivo.
- **Textos, diseño o fórmulas:** editar `index.html`.

Dos formas de editar:

1. **Desde el navegador:** abrir el archivo en github.com, pulsar el lápiz, cambiar y "Commit changes".
2. **Desde el ordenador:** editar los archivos de esta carpeta y luego `git add -A && git commit -m "cambio" && git push`.

## Enlaces

- `?u=3604` abre directamente una unidad (el `id` de `unidades.js`).
- El botón "Copiar enlace" añade al enlace los campos editados.
- "Guardar unidad" guarda solo en el navegador de quien la usa; para que una unidad la vea todo el mundo hay que añadirla en `unidades.js`.
